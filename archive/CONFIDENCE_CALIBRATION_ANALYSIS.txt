================================================================================
ROOT CAUSE ANALYSIS
================================================================================

RMSE by prop type:
- ASSISTS: 2.03 (lowest) → narrowest bands → artificially high confidence
- THREES: 1.54 (second lowest) → narrow bands → massively overconfident
- REBOUNDS: 2.71 (moderate) → moderate bands → moderately overconfident
- POINTS: 6.66 (high) → wide bands → confidence too low for good bets
- PRA: 8.43 (highest) → widest bands → excluded from high-confidence bets

The formula treated all props identically except for multiplier adjustments,
but those adjustments were based on RMSE magnitude, NOT historical accuracy.

================================================================================
SOLUTION: ACCURACY-BASED CALIBRATION
================================================================================

METHOD:
1. Analyzed 61,320 predictions with actual outcomes
2. Calculated accuracy rate (predictions within ±1 RMSE) for each prop type
3. Set target: confidence score = accuracy - 3% (conservative)
4. Calculated optimal multiplier: (90 - target_confidence) / (2 × RMSE)

RESULTS:

REBOUNDS     2.71    71.7%       3.0         3.9         +0.9
THREES       1.54    67.1%       3.2         8.4         +5.2  (MAJOR)
PRA          8.43    71.4%       2.8         1.3         -1.5

KEY CHANGES:
